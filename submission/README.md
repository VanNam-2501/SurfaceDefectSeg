# Hồ sơ dự án

Thư mục này lưu các tài liệu phục vụ báo cáo và kiểm chứng kỹ thuật:

| Thư mục | Nội dung |
| --- | --- |
| `01_report/` | Mã tạo báo cáo và hướng dẫn biên soạn |
| `02_slides/` | Hướng dẫn chuẩn bị slide |
| `03_source/` | Bản đồ mã nguồn |
| `04_demo_video/` | Hướng dẫn quay demo |
| `05_logs/` | Nhật ký phát triển |
| `07_evidence/` | Nguồn gốc dữ liệu, manifest mô hình và kết quả xác minh |

Dataset, checkpoint, báo cáo nhị phân, video, raw prompt export và tài liệu có chữ ký không được lưu trong repository. Các nội dung này được quản lý trong gói bàn giao riêng.
